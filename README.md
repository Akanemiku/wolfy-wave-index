# 狼波周期指数 · Wolfy Wave Index

比特币四年周期理论的专业指标网站：完整 BTC 日线 K 线（2013 年至今，对数坐标，
可缩放/平移），图上刻有固定标注——由狼波周期指数推导的牛市/熊市区间
（纯区块制，铺满全轴含未来推演）、减半日竖线、基于实际价格枢轴的周期时长
标尺。标注只能看，不能改。

页面功能：**区块高度主横轴**（底部刻度轴同时显示高度与对应 ≈日期，十字线
在轴上有「高度 · 日期」浮标）、144/1,008/4,368 块分桶切换、深/浅主题切换
（默认深色）、对数/线性坐标切换、标注显隐开关、十字线 OHLC 读数、顶栏实时
价格与周期状态。图表上方有一条标签轴，专门容纳「减半日」「今日」等事件文本，
随缩放平移实时跟随。

**为什么以区块为主轴**：减半理论本质上以区块为时钟——横轴用区块高度后，
减半线严格等距（210,000 块一格），K 线按固定块数分桶，时长标尺显示各周期
的实际块数，进行中熊市的预测终点 = 牛顶高度 + 历史熊市块数均值。日期↔高度
映射基于 mempool.space 的难度调整锚点（`data/btc-heights.json`，
`node scripts/fetch-heights.mjs` 可刷新），页面加载时自动补当前链上高度；
刻度上的日期为按出块速度换算的近似值（≈）。

**狼波周期指数（Wolfy Wave Index）**（下方独立副图区的金色锯齿折线，
TradingView 指标面板风格，分隔条可拖拽调整高度）：0 = 熊底，1 = 牛顶，
**纯区块制**——不参考现实时间与实际价格顶底，整条锯齿仅由减半区块网格推导：
周期 = 210,000 块，牛三熊一 → 牛市 = 减半 ± 78,750 块（0 → 1 线性，减半日
恰为 0.5），熊市 = 其余 52,500 块（1 → 0 线性），按减半网格无限周期延拓。
两种横轴视图读同一个函数（时间视图先把日期换算成区块高度），读数一致；
「今日」之后为虚线未来段，右轴实时显示当前指数值。指数峰谷与图上按实际
价格标注的牛顶/熊底之间的偏差，正是「理论时钟 vs 实际市场」的观察点。

**未来推演**：横轴一直铺到「下下个」理论熊底（覆盖完整的下一轮周期），
未来的减半线（区块高度精确；时间视图的日期按当前出块速度估算、画虚线）
与狼波指数的未来锯齿都直接画出。页面加载时默认聚焦当前周期（上轮实际
熊底 → 本轮预测见底），滚轮缩小即可查看过去全史与未来推演。

## 本地运行

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

不能直接双击 index.html（file:// 下无法 fetch 本地数据文件）。

## 数据来源

- 历史快照：`data/btc-daily.json`（Bitstamp BTC/USD 日线，随仓库分发）
- 页面加载时从 Bitstamp 拉取最近 1000 天实时合并；失败则用 Coinbase 备用；
  再失败则只显示快照并提示横幅
- 快照覆盖最近 1000 天内都无需更新；想刷新运行：

```bash
node scripts/fetch-history.mjs   # 需 Node ≥ 18
```

## 调整标注

只需要改 [js/config.js](js/config.js)：

- 顶底**不是**硬编码日期——牛顶 = 搜索窗口内最高价那天、熊底 = 窗口内最低价那天，
  由实际行情自动算出（`PIVOT_WINDOWS` 定义粗略窗口）
- 减半日：`HALVINGS`
- 预测规律：`BEAR_DAYS`（熊市 364 天）
- 箭头文字：`ARROW_LABEL_MODE = 'fixed'`（周期理论数字）或 `'computed'`（实际天数）
- 配色：`THEMES.dark` / `THEMES.light`（想改红涨绿跌就交换 `up`/`down`）

## 部署

纯静态站，无构建步骤：

- **GitHub Pages**：推到 GitHub → Settings → Pages → main 分支根目录
- **Vercel**：导入仓库，Framework 选 "Other"，无需构建命令

## 技术栈

[TradingView Lightweight Charts](https://github.com/tradingview/lightweight-charts) v5.2.0
（已内置于 `vendor/`，Apache-2.0），标注用 series primitives 实现（纯 Canvas 渲染，
无交互命中，天然只读）。无框架、无依赖、无构建。
